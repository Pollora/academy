# Pollora Academy

Learn Pollora 13 and AI-assisted development with [Nectar](https://pollora.dev/nectar/overview/): short theory, quizzes, and exercises graded by tests on your own machine. Self-paced, in French and English.

Apprenez Pollora 13 et le développement assisté par IA avec Nectar : de la théorie courte, des quiz, et des exercices corrigés par des tests sur votre machine. En autoformation, en français et en anglais.

## Layout

| Folder | What it is |
| --- | --- |
| `site/` | The learning site (Astro 7 + Starlight), in the Pollora design. |
| `lab/` | The exercise project, graded by Pest tests. *Not there yet.* |

## Run the site

```bash
cd site
npm install
npm run dev
```

Astro 7 needs Node 22.23.4 or later (`site/package.json` pins it for [Volta](https://volta.sh)).

## Contributing

Facts come from the [official documentation](https://pollora.dev), which stays the source of truth: link to it rather than copy it. Each module states the Pollora version it was tested with.
